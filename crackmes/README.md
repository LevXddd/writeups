# crackmes

Writeups for [crackmes.one](https://crackmes.one) challenges, one folder per crackme:

```
crackmes/
└── <author>-<name>/
    ├── README.md   # the writeup (copy ../TEMPLATE.md)
    └── solve.py    # keygen / solver, if any
```

Don't commit the challenge binaries themselves; link to the crackme page instead.
