# pwn.college notes

Concept notes from working through [pwn.college](https://pwn.college) dojos.

pwn.college asks students **not to publish challenge solutions**, so this folder
only explains the ideas: what a technique is, why it works, and where to read more.
No flags, no challenge-specific steps.

Suggested layout, one file per topic:

```
pwn-college-notes/
├── 01-linux-luminarium.md
├── 02-computing-101.md
└── ...
```
